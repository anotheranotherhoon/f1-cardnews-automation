# Spec: character-asset-library

## ADDED Requirements

### Requirement: 캐릭터 원본의 단일 관리
각 드라이버는 승인된 원본 캐릭터 이미지(base.png, 투명배경) 1개를 가져야 하며(SHALL), 해당 드라이버가 등장하는 모든 생성물은 이 원본 또는 승인된 파생 포즈를 레퍼런스로 사용해야 한다(MUST).

#### Scenario: 기존 드라이버의 밈 표지 생성
- **WHEN** 베르스타펜이 등장하는 밈 표지를 생성
- **THEN** 저장된 base.png(또는 적합한 pose)가 Gemini에 레퍼런스 이미지로 전달된다

### Requirement: 통일 화풍 프롬프트 상수
모든 캐릭터 생성·편집 요청에는 동일한 스타일 가이드 프롬프트 상수가 포함되어야 한다(MUST). 화풍 상수는 설정으로 한 곳에서 관리한다.

#### Scenario: 서로 다른 드라이버의 캐릭터 생성
- **WHEN** 두 드라이버의 캐릭터를 서로 다른 시점에 생성
- **THEN** 두 결과물은 동일한 화풍 규격(스타일 가이드 상수)으로 생성된다

### Requirement: 신규 캐릭터의 lazy 생성과 승인
base가 없는 드라이버가 처음 필요해지면 시스템은 캐릭터를 생성해 텔레그램 승인을 거친 뒤에만 저장·사용해야 한다(SHALL).

#### Scenario: 시즌 중 데뷔 드라이버
- **WHEN** 라이브러리에 없는 드라이버가 밈 표지에 필요해짐
- **THEN** 캐릭터 후보가 생성되어 승인 요청이 전송되고, 승인 후 base.png로 저장된다

### Requirement: 승인된 파생 포즈의 축적
승인 루프를 통과한 신규 포즈 이미지는 해당 드라이버의 poses/ 디렉토리에 저장되어야 한다(SHALL). 이후 동일·유사 상황에서는 저장된 포즈를 우선 재사용한다.

#### Scenario: 트로피 포즈 재사용
- **WHEN** 과거에 승인된 "트로피 들기" 포즈가 존재하는 드라이버가 다시 우승
- **THEN** 신규 생성 없이 저장된 포즈가 후보로 우선 사용된다
